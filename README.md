# FlyRank FE-AA2 — Your First 3D Experience

An interactive 3D product configurator built with React Three Fiber and Three.js.

## Features

- Real-time 3D product scene with studio lighting
- Orbit, zoom, and drag controls
- Finish/material switching
- Auto-rotate interaction
- Product specifications panel
- Suspense loading fallback
- Responsive layout with a mobile-friendly control panel
- Performance-conscious rendering with a capped DPR

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Assignment

FlyRank Frontend AI Engineering — FE-AA2, Week 7. The experience demonstrates a real 3D browser scene, a meaningful interaction beyond orbiting, and responsible performance-oriented delivery.
